# Quick Start

A quick guide to using Library File Manager — no admin setup here, just how to use the app.

## Opening the app

Find **Library File Manager** in the App Launcher and open it. You'll land on a **Getting Started** page first — it gives you a quick overview, and a button to jump straight into the file manager.

## Browsing your files

On the **Library File Manager** tab, you'll see two things:

- A **tree** on the left showing all your libraries and their folders
- A **file table** on the right showing what's inside whatever you've selected

Click a library or folder name in the tree to open it and see its files. Folders also show up as rows right in the file table (with a folder icon) — click one to jump straight into it, same as clicking it in the tree.

## Moving files

1. Check the box next to one or more files in the file table.
2. Click **Move Files** at the top.
3. Pick where you want them to go — any library, or any folder inside any library, even a totally different library than where they are now.
4. Click **Move Files** to confirm.

That's it — you can move files between libraries in one step, which the standard Salesforce Files screen doesn't let you do.

## Creating a folder

1. Select a library or folder in the tree first (the **Create Folder** button stays greyed out until you do).
2. Click **Create Folder**.
3. Type a name and confirm.

## Deleting files

1. Check the box next to the file(s) you want to remove.
2. Click **Delete Files**.
3. Confirm — deleted files go to the Recycle Bin, same as anywhere else in Salesforce.

## Tips

- **Expand All** / **Collapse All** (next to the refresh button above the tree) open or close every folder in the tree at once.
- The **Move Files** and **Delete Files** buttons only turn on once you've selected at least one file — that's not a bug, it's there to stop you from clicking them with nothing selected.
